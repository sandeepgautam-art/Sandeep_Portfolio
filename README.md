# Sandeep Gautam | IT Portfolio

A responsive, single-page portfolio for an Information Technology engineering student graduating in 2027. Built with plain HTML, CSS and JavaScript so it is easy to edit and deploy.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser, or use VS Code with the Live Server extension.
3. Edit content in `index.html`, styles in `style.css`, and interactions in `script.js`.

## Features

- Responsive layout for desktop, tablet and mobile
- Hero section with GitHub, LinkedIn, email and CV links
- About section, categorized skills, projects, education/training, certifications and contact details
- Filterable project cards, including Netflix Data Analysis
- Mobile navigation menu
- Scroll reveal effects with reduced-motion support
- Downloadable CV copy in `assets/Sandeep_Gautam_CV.docx`
- No framework or build step required
